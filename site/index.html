Edge-Healer: Decentralising Kubernetes with Edge Self-Healing

Davide Lamagna

Read the write-up Read the paper See the poster View the code

Kubernetes keeps one central brain: the API server, the scheduler and the controllers that replace lost Pods. At the edge, that brain sits on the far side of a thin WAN link. When the link drops, a Pod that dies on a factory gateway stays dead until the link comes back.

edge-healer gives every node just enough of a brain to fix that. An agent on each node gossips its free CPU to its peers through a Serf sidecar. When a Pod goes missing and the API server is unreachable, the agents bid, and the node with the most spare CPU recreates the Pod locally. When the WAN returns, the local changes are reconciled with the control plane.

The experiment, live
